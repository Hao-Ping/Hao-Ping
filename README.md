## 🔭 Featured Projects

### 🐄 Real-time Open-World Cow Face Re-ID System &nbsp;`Python · PyTorch · ONNX · Qt · FAISS`
> Real-time identity retrieval system running at **15 FPS** across **600+ identities**
- **93.8% Rank-1 accuracy · 95.1% mAP · 98.1% F1-score** — open-world re-ID
- ResNet50 + ArcFace backbone, optimized via ONNX + FAISS-GPU for fast similarity search
- Multi-threaded producer-consumer pipeline with H.264 buffering

### 🖼️ Image Processing Desktop Application Suite &nbsp;`C++ · Qt · OpenCV`
> Full-featured desktop toolkit covering classical and modern image processing
- FFT, Hough Transform, Marr-Hildreth edge detection; real-time responsive GUI
- SIFT / SURF / ORB feature extraction · camera calibration · k-means segmentation
- Modular architecture separating processing logic from UI rendering; used as TA teaching material
